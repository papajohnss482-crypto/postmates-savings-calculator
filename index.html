Percentage code or flat code: which wins?

The answer changes with order size, and the crossover is simple math: the flat amount divided by the percentage. A $10 flat code against a 20 percent code crosses over at a $50 order. Below $50 the flat code wins, above $50 the percentage code wins. Terms below are worked examples using sample code terms, real codes carry their own terms and minimums.
